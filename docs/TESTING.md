## 桌面集成验证

已在真实 Harness 0.2.2-rc.1 桌面版验证过以下流程：

- 千条规模的本地只读预览、后台任务、即时进度和确认窗口。
- 统一导入侧栏、原项目分组、未逐条打开的标题搜索及真实正文打开。
- 图片预览与提示词收起、工具输出折叠、问答卡片。
- 1907 字符 / 72 行用户文本的截取、展开、字号控制和收起。
- 增量预览识别源未变化及变化会话，停在确认界面，不自动执行批量同步。

真实查看对话时，Harness 可能追加 `session/end-seed` 等原生初始化事件。验证以原始压缩字节前缀保持完整、没有来源导入/删除/覆盖为依据，不能把正常打开会话等同于所有文件哈希始终不变。

## 验证限制

- 已适配版本以外的 Harness API 可能变化，应重新执行集成验证。
- 自动化测试通过不代表所有历史 Codex 数据格式都已覆盖。
- 远程附件不会自动下载；原文件缺失且无内嵌副本时，测试只能验证明确报错与占位行为。
- Linux 原生锁和不同平台附件处理需以对应平台测试结果为准；Windows 清理不在当前支持范围内。

## 可选：本机只读格式检查

以下脚本会读取指定 Codex 数据目录并验证原生事件结构，不写入 Harness，也不复制附件。输出包含原会话 ID 与诊断，公开分享前应脱敏：

```sh
node test/verify-local.mjs /absolute/path/to/.codex
```

它属于显式本机诊断，不在 `npm test` 或 CI 默认流程中运行。

ChatGPT 导出与本机数据的只读重合诊断：

```sh
npm run audit:chatgpt -- /absolute/path/export.zip
```

结果为统计、匹配 ID 与错误；不输出正文或账户资料。仅精确文本和来源 ID 匹配，不进行语义相似搜索，也不据此自动合并会话。
